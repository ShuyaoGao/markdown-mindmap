    操作说明 （随时按 H 或右上角 “?” 再打开）
    
    
    
    
    
      
    
        
    这是什么
    
        
    一个键盘优先的思维导图：像 XMind 一样回车建同级、Tab 建子级，几分钟画出一棵树。左边的 Markdown 文本框和右边的图实时互转：改文字图跟着变，改图文字跟着变。全部在浏览器里完成，不联网，自动保存在本机。
    
        
    三个模式（页面顶部）
    
        
      
          
    • 观看：示例地图自动逐层展开，每一步配解说（这门课的知识树 / 论文写作结构 / 一周计划）。
      • 
          
    • 我来画：自己画。工具条里有布局（左右平衡 / 向右树状 / 大纲）、连线、配色、打开 / 下载文件、导出 PNG / SVG。
      • 
          
    • 练习：按任务清单一步步做，完成一项自动打勾。
      • 
        
    
        
    Markdown 怎么写
    
        
    # 中心主题
## 分支（## 是第二层）
- 子节点（缩进两格再深一层）
  - 孙节点
<!-- 紧跟在节点后面的注释 = 备注 -->
    
        
    节点文字支持 **粗体**、`代码`、[文字](网址)。也能打开 FreeMind .mm 和 OPML 文件。
    
      
    
      
    
        
    
          
    键位表
    
          
    
            
    Enter新建同级（根节点上 = 新建子级）
    
            
    Tab新建子级
    
            
    Shift+Tab升一级
    
            
    空格 / F2编辑文字（编辑中 Enter 确认、Esc 取消、Tab 确认并建子级）
    
            
    Delete / Backspace删除（带子树会先确认）
    
            
    ↑ ↓ ← →在树上移动选中
    
            
    Ctrl+Enter在上方插入同级
    
            
    Ctrl+↑ / ↓调整同级顺序
    
            
    Ctrl+/折叠 / 展开（折叠后显示子节点数）
    
            
    Ctrl+Z / Y撤销 / 重做
    
            
    Ctrl+F查找节点
    
            
    Ctrl+0 / M适应窗口 / 显示收起 Markdown
    
            
    Home · Esc · H回到根节点 · 取消 · 本说明
    
          
    
          
    鼠标：滚轮缩放，空白处拖动平移，拖节点到另一个节点上换父级（目标会高亮），双击编辑。
    
        
    
        
    
          
    触屏操作
    
          
          
    手机 / 平板：上面是图，下面一排大按钮；「编辑」时输入框出现在键盘上方。右上角 ☰ 里有「看 Markdown」（全屏改文字）、「大纲 · 统计」、打开 / 下载 / 导出和退出。
    
        
    
        
    关于离线
    
        
    纯静态网页：不联网、不上传任何内容；导图自动保存在本机浏览器里（localStorage），换电脑要先「下载 .md / .json」。关掉标签页就全部结束。
